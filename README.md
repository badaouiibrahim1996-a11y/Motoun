# المسمّع الذكي | Smart Mosamie

واجهة عربية (RTL) متجاوبة لتجربة تسميع المتون العلمية. النسخة الحالية نموذج أولي من جهة التعرف الصوتي، وتعتمد على واجهة SpeechRecognition التي يوفرها المتصفح إن كانت مدعومة.

## الميزات
- مكتبة أولية تتضمن جزءاً من أبيات المنظومة البيقونية.
- اختيار نطاق الأسطر المراد تسميعها.
- عرض النص المرجعي وإخفاؤه.
- تعرف صوتي تجريبي حي عبر المتصفح.
- مقارنة تقريبية للكلمات مع النص وتقرير للجلسة.
- إضافة متون خاصة، تُحفظ في localStorage على الجهاز الحالي.
- وضع داكن، وتصميم متجاوب، وملفات PWA مبدئية.

## معاينة سريعة على GitHub Pages
1. أنشئ مستودعاً جديداً في GitHub.
2. ارفع جميع الملفات الموجودة في هذا المجلد إلى جذر المستودع، مع الحفاظ على أسماء الملفات.
3. افتح **Settings → Pages**.
4. ضمن **Build and deployment** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/(root)`، واضغط Save.
5. انتظر ظهور رابط الموقع في صفحة Pages وافتحه في Chrome على Android.
6. اسمح للمتصفح باستخدام الميكروفون إذا طلب ذلك. قد تختلف إتاحة التعرف الصوتي حسب المتصفح والمنطقة والاتصال.

## تنبيهات مهمة
- GitHub Pages يستضيف الواجهة الثابتة فقط؛ لا يوجد خادم صوتي خاص في هذه النسخة.
- Web Speech Recognition ليس متاحاً في كل المتصفحات، وقد يحتاج اتصالاً بالإنترنت حتى لو كانت الواجهة مخزنة محلياً.
- المقارنة الحالية تقريبية وتعتمد على نص ASR، وليست نموذجاً متخصصاً في ضبط ألفاظ المتون أو أحكام النطق.
- النص المضمن للبيقونية مختصر للتجربة ويجب مراجعته على نسخة موثوقة قبل الاستخدام الجاد. أضف النص المعتمد بنفسك عند الحاجة.
- البيانات المضافة تحفظ في متصفح الجهاز فقط؛ حذف بيانات الموقع أو استخدام جهاز/متصفح آخر قد يؤدي إلى فقدها.
- الخط العربي من Google Fonts اختياري؛ عند عدم توفر الإنترنت سيستخدم النظام خطوطاً احتياطية.

## التطوير القادم
1. اعتماد نص كامل موثوق للبيقونية مع ضبط الأبيات ومصدرها.
2. اختبار محرك تعرف عربي على تسجيلات فعلية للمتون.
3. تحسين المحاذاة باستخدام خوارزمية تسلسل مناسبة بدلاً من المقارنة التقريبية الحالية.
4. إضافة خادم API فقط إذا تطلب محرك الصوت ذلك.
5. دراسة نموذج محلي يعمل على Android لدعم العمل دون اتصال.


### إذا بقيت تظهر النسخة القديمة على الهاتف
بعد رفع الملفات، افتح الموقع في Chrome ثم أعد تحميله. إذا لم تتغير النسخة: افتح إعدادات Chrome > إعدادات المواقع > اختر موقعك > محو البيانات وإعادة الضبط، ثم افتح الموقع من جديد. تم تحديث إصدار Service Worker إلى v2 لإجبار المتصفح على تجديد الملفات المخزنة.
